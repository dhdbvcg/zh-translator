# 网页测试台

配套 `zh-translator` 的浏览器端测试界面:既是交互式翻译控制台,
也是一键自检工具。

## 启动

```bash
zhtrans --serve --port 8848
#
# 浏览器打开 http://127.0.0.1:8848/
```

> **重要:启动后请保持该终端窗口开启。**
> 服务是前台进程,窗口关闭或按 Ctrl-C 都会停止服务,
> 此时页面仍能打开(静态文件已加载),但所有翻译请求会报
> "Failed to fetch" / "无法连接翻译服务"。
>
> 首次启动需加载模型,约 60–90 秒,期间接口尚未就绪。

服务启动时会自动托管本目录(`web/`),无需另外起静态服务器。
如需关闭静态页面托管:`zhtrans --serve --web off`。

## 页面功能

### 翻译台

- 输入框边打边译(500ms 防抖),回车立即翻译
- 源语种可选「自动识别」或从 121 种语言中指定
- 目标可选简体 / 繁体
- `beam` 宽度可调(1 最快,4 默认,8 更准)
- 14 个样例按钮,覆盖大小语种(含斯瓦希里语、高棉语、缅甸语、祖鲁语)
- 术语表开关:填 `{中文译词: 源语种术语}`,如 `{"开放人工智能":"OpenAI"}`
- 显示源语种代码、是否自动识别、耗时

### 批量翻译

每行一句,可混合语种,自动按语种分组批量解码。

### 接口自检

依次验证 8 项,带耗时与逐项结果:

| # | 项目 | 验证内容 |
|---|------|----------|
| 1 | `GET /health` | 服务可用、返回设备类型 |
| 2 | `GET /langs` | 语种数 > 50,并渲染语种表 |
| 3 | `POST /translate en` | 指定语种,译文含中文 |
| 4 | `POST /translate auto` | `detected=true` 且识别为德语 |
| 5 | `POST /translate zh-Hant` | 繁体通道产出中文 |
| 6 | `POST /translate` 空文本 | 返回 `skipped=true` 而非报错 |
| 7 | `POST /translate` 非法语种 | 被拒绝且返回 **400**(而非 500) |
| 8 | `POST /batch` | 3 条混合语种,分别识别为 en/de/fr |

### 语种表

展示全部支持语言,可按名称 / ISO 代码 / 语系搜索,
或按资源层级筛选(★ 语料充足 / ☆ 中等 / · 低资源)。
点击任一语言即可设为源语种。

## 文件

```
web/
  index.html   页面结构
  style.css    样式(深色主题,无外部依赖)
  app.js       API 客户端、翻译交互、自检逻辑
```

## 命令行自检

不打开浏览器也可跑同样的断言(与页面里的 8 项一一对应):

```bash
zhtrans --serve --port 8848          # 终端 1
set ZT_PORT=8848                     # 终端 2(PowerShell)
python tests/web_selftest.py
```

```bash
ZT_PORT=8848 python tests/web_selftest.py   # Linux / macOS
```

## 说明

- 页面与后端同源,不产生跨域问题
- 纯静态资源,无任何外部 CDN 依赖,可离线使用
- 服务端的静态托管做了目录穿越防护(路径越界返回 404)
